호남각 포토존 V3
1. ZIP 압축 해제
2. GitHub 저장소 루트에 index.html, vercel.json, assets 폴더 전체를 업로드합니다. ZIP 자체를 올리면 안 됩니다.
3. Vercel 자동 배포 Ready 확인 후 https://honamgakphotozone.vercel.app 에 접속합니다.
4. PC에서는 실제 호남각 사진으로 미리보기, 휴대폰에서는 카메라 허용 후 실시간 사진 촬영 가능합니다.
5. 캐릭터는 기존 합성 그림에서 추출한 PNG이므로 완벽한 투명 누끼/3D 공간 추적이 아닙니다.
6. 배경은 사용자가 제공한 실제 호남각 정면 사진을 야간 톤으로 보정한 것으로, 실제 야간 촬영 사진은 아닙니다.
